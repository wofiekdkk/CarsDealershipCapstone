# Car Dealership Review Platform

## Project Name
Car Dealership Review Platform

## Project Description
A full-stack web application developed as part of the IBM Full Stack Software Developer Capstone. Users can browse dealerships, view dealership details, register, log in, and submit customer reviews.

## Technologies
- Python and Django
- React and JavaScript
- Node.js and Express
- MongoDB
- HTML and CSS
- REST APIs

## Main Features
- User registration and authentication
- Browse car dealerships
- Filter dealerships by state
- View dealership details
- Read and submit customer reviews
- Car make and model selection
- Review sentiment analysis

## Project Structure
- `server/` – Django backend and React frontend
- `server/database/` – Node.js and MongoDB API
- `server/frontend/` – React components and static pages

## Purpose
This project was developed as part of the IBM Full Stack Software Developer Capstone.
